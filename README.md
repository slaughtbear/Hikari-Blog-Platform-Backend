# ⛩️ Hikari

Backend para una plataforma web de blog personal enfocado en simplicidad, rendimiento y escalabilidad.

Proporciona endpoints RESTful para la gestión de usuarios, publicaciones y autenticación JWT.

Forma parte de un proyecto full-stack junto al frontend en **React** + **TailwindCSS** (Próximamente).
